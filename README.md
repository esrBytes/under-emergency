
# Under Emergency

## Under Emergency Database

Project Overview

Under Emergency is an emergency triage system designed to help assess patients based on their reported symptoms and injuries and provide an appropriate triage result.

This repository contains the SQL database used by the Under Emergency project.

Database

The database is built using MySQL.

It contains the tables, relationships, primary keys, foreign keys, constraints, and sample data required for the project.
